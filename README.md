# 🚀 Yash Agarwal's Portfolio Website

Welcome to my personal portfolio website — a lightweight, responsive web presence built using **HTML5**, **CSS3**, and **JavaScript**. It showcases my projects, skills, certifications, and experience in a clean, accessible format.

## 🌐 Live Site

🔗 [https://yashagx.vercel.app](https://yashagx.vercel.app)

## 🎯 Purpose

This project aims to:
- Serve as a digital portfolio and résumé
- Highlight skills, certifications, and experience
- Showcase personal and academic projects
- Present a structured and professional profile

## 🛠️ Tech Stack

- **HTML5** – Semantic page structure
- **CSS3** – Custom styling and layout
- **JavaScript** – Interactive features and dynamic behavior

- ## 📁 Project Structure

~~~
yashagx-portfolio-website/
│
├── assets/                     # Images and media files
├── css/                        # Custom stylesheets
├── js/                         # JavaScript scripts
├── index.html                  # Main landing page
└── README.md                   # Project documentation
~~~


## 💡 Features

- Fully responsive design for all screen sizes
- Modular codebase that's easy to maintain
- Dynamic rendering using JSON for skills
- Certificate and experience sections with visuals
